INKBOUND BRAND ASSETS

Generated from the approved Inkbound icon artwork.

Contents:
- master/inkbound-master-icon-1024.png
- google-play/inkbound-google-play-512.png
- favicons/ PNG sizes plus favicon.ico
- pwa/ 192, 512, maskable 512, and Apple touch 180
- android/res/ legacy launcher PNG density folders

Important:
The Android files included here are ready-to-use legacy launcher PNGs.
A true Android adaptive icon should use separately authored foreground/background
layers rather than simply splitting a flattened illustration. Keep the master
artwork as the source when creating those layers in Android Studio Image Asset.

Google Play:
Use google-play/inkbound-google-play-512.png for the 512x512 store icon.

Web:
Use favicons/favicon.ico plus the PNG favicon/PWA assets as appropriate.
